# PROJECT 이음 - 개발 로드맵

## 1. 문서 목적

본 문서는 기존 기획 문서에 명시된 기능의 개발 순서를 정리한다.

기능의 세부 구현 방식, 상태 구조, 데이터 구조, 판정 수치 및 담당자 배정은 본 문서에서 결정하지 않는다. 해당 내용은 개발 과정의 프로토타입 테스트와 팀 협의를 통해 확정한다.

## 2. 개발 순서

### 1단계: 메인 화면 및 기본 설정

1. 메인 화면
2. 옵션
3. 로컬 저장

### 2단계: 기본 조작

1. 컨트롤러 기반 오브젝트 잡기 및 놓기
2. 기본 이동 및 회전
3. 조작 튜토리얼

### 3단계: Chapter 1 도리 제작

1. 작업 부재 및 새 재료 관리
2. 먹매김
3. 톱질
4. 끌질
5. 공정 평가
6. Chapter 1 진행 관리

### 4단계: Chapter 2 도리 설치

1. 도리 설치
2. 공포 퍼즐
3. Chapter 2 진행 관리

### 5단계: 진행 보조 기능

1. 노장 대사
2. HUD 및 안내 UI
3. 일시정지 메뉴
4. 저장 및 이어하기
5. 사운드
6. 오류 및 복구

### 6단계: 전체 화면 흐름

1. 프롤로그
2. 엔딩
3. 메인 화면 복귀

### 7단계: 이음이 AI 음성 대화

1. PTT
2. STT
3. LLM 응답
4. 안전성 검사
5. TTS
6. 응답 실패 시 고정 대사
7. 현재 공정 데이터 전달
8. 오프라인 대응

### 8단계: 통합 및 기기 검증

1. 전체 시나리오 통합
2. Meta Quest 3 조작 검증
3. 저장 및 이어하기 검증
4. 공정별 평가 검증
5. AI 실패 및 오프라인 진행 검증
6. 시작부터 엔딩까지 전체 완주 검증

### 9단계: 후순위 개선

1. 도움 단계 자동 조절 고도화
2. 더 세밀한 목재 메시 변형
3. 다양한 이음이 질문
4. 공정별 세부 결과 분석
5. 엔딩 결과 다시 보기
6. 프롤로그 다시 보기

## 3. 개발 중 결정 사항

다음 항목은 본 로드맵에서 확정하지 않는다.

- 오브젝트 잡기 허용 거리
- 이동 및 회전 방식
- 먹선 필요 개수
- 먹매김 허용 위치 및 각도 오차
- 톱질 유효 속도 범위
- 절단면 평가 기준
- 끌 타격 유효 속도
- 홈의 목표 폭과 깊이
- 부재 손상도 최대값
- 도리 설치 스냅 거리와 각도
- 스냅 즉시 고정 여부
- 공포 퍼즐 부재 개수와 설치 순서
- 공정별 매우 우수 및 합격 기준
- 노장 음성의 사전 녹음 여부
- PTT 버튼 배치
- 이음이 고정 힌트 문장
- 실패 부재 최대 표시 개수
- 프롤로그 건너뛰기 허용 여부
- 기능별 내부 상태 구조
- 데이터 및 코드 구조

위 항목은 프로토타입 테스트 또는 팀 협의를 통해 결정하고, 확정된 내용은 해당 기능 문서에 반영한다.
