# PROJECT 이음 - 평가·설치·퍼즐

## 1. F-010 공정 평가 시스템

### 1.1 기능 정의

먹매김, 톱질, 끌질, 도리 설치, 공포 퍼즐의 결과를 계산 규칙에 따라 평가하는 기능이다.

### 1.2 평가 시점

각 공정 종료 직후 자동으로 실행한다.

공정 완료 요청  
↓  
필수 기록 확인  
↓  
점수 계산  
↓  
등급 판정  
↓  
결과 UI 표시  
↓  
노장 피드백  
↓  
다음 공정 또는 재시도

### 1.3 평가 영역

#### 정확도

- 목표 위치 오차
- 각도 오차
- 깊이 오차
- 설치 틈새
- 최종 구조 일치 여부

#### 과정 안정성

- 불필요한 손상
- 잘못된 조작 횟수
- 작업 순서
- 재료 교체 횟수
- 재도전 횟수

#### 학습 참여 기록

- 설명 재생 여부
- 힌트 요청 여부
- 이음이 질문 횟수
- 노장 피드백 확인 여부

학습 참여 기록은 통과 여부에 영향을 주지 않는다.

### 1.4 등급 판정

등급은 정확도와 과정 안정성을 기반으로 한다.

| **등급**  | **기본 조건**                             |
|-----------|-------------------------------------------|
| 매우 우수 | 높은 정확도 기준 충족 및 치명적 실수 없음 |
| 합격      | 최소 허용 기준 충족                       |
| 불합격    | 최소 허용 기준 미달                       |

### 1.5 평가 피드백

노장은 숫자를 직접 읽지 않고 작업 결과를 설명한다.

예시:

#### 매우 우수

“먹선도 곧고, 톱도 흔들리지 않았구나. 이 정도면 다음 작업을 맡겨도 되겠다.”

#### 합격

“조금 거친 곳은 있지만 결구에는 문제가 없겠구나. 다음으로 넘어가자.”

#### 불합격

“홈의 한쪽이 너무 깊구나. 이대로 끼우면 틈이 생길 게다.”

### 1.6 오류 처리

평가에 필요한 기록이 누락된 경우:

- 임의로 합격 처리하지 않는다.
- 오류 메시지를 내부 로그에 기록한다.
- 해당 공정의 시작 지점으로 복귀한다.
- 플레이어에게는 자연스러운 재시작 안내를 제공한다.

## 2. F-016 공포 퍼즐 시스템

### 2.1 기능 정의

플레이어가 완성 구조 이미지를 참고해 여러 공포 부재를 올바른 순서와 방향으로 설치하는 기능이다.

### 2.2 시작 조건

- Chapter 1 완료
- 공포 퍼즐 부재 생성 완료
- 목표 구조 데이터 로드
- 완성 예시 이미지 표시
- 노장 설명 완료
- 플레이어가 도리를 잡을 수 있는 상태

### 2.3 퍼즐 구성

- 완성된 공포 구조 참고 이미지
- 조립 가능한 여러 부재
- 부재별 설치 목표 위치
- 설치 순서 조건
- 설치 고스트
- 자석식 스냅 기능

### 2.4 정상 흐름

완성 구조 확인  
↓  
부재 선택  
↓  
부재 잡기  
↓  
설치 위치 접근  
↓  
파란색 반투명 부재 고스트 표시  
↓  
위치와 방향 정렬  
↓  
판정 범위 진입  
↓  
자석식 스냅  
↓  
부재 설치 완료  
↓  
다음 부재 선택  
↓  
모든 부재 설치  
↓  
완성 구조 판정

### 2.5 설치 목표 표시

플레이어가 부재를 잡으면 해당 부재가 설치될 수 있는 위치에 파란색 반투명 부재 형태를 표시한다.

### 2.6 설치 순서

순서가 정해진 퍼즐의 경우:

- 현재 설치 가능한 부재만 유효 처리
- 다음 순서의 부재는 잡을 수 있으나 스냅되지 않음
- 반복 시 노장이 구조의 아래쪽부터 살펴보라는 힌트 제공

순서가 자유로운 부재는 목표 위치와 방향만 판정한다.

### 2.7 잘못된 부재

잘못된 부재를 설치 위치에 가져간 경우:

- 고스트가 표시되지 않음
- 스냅 발생 안 함
- 억지로 통과되지 않음
- 3회 연속 잘못된 시도 시 이음이 힌트

### 2.8 퍼즐 완료

모든 부재가 목표 위치에 설치되면:

- 전체 구조 일치 확인
- 공포 구조 강조 효과
- 목재 결합 완료음
- 노장 완료 대사
- 평가 실행
- 엔딩으로 진행

### 2.9 평가 요소

- 올바른 부재 선택
- 설치 순서
- 방향 정확도
- 잘못된 시도 횟수
- 힌트 사용 횟수
- 전체 소요 시간

> 공포 퍼즐 챕터에서는 불합격은 존재하지 않고, 수행 시간에 따른 노장의 피드백만 존재한다.
