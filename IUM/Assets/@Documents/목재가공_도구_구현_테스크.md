# 목재 가공 도구 구현 태스크 (Task List)

- [ ] **에디터: ChiselTool 프리팹 계층 세팅**
  - [ ] `ChiselTool` 하위에 가이드 그래픽 역할을 할 `ProjectionVisual`(Quad Mesh 또는 Decal Projector) 오브젝트 추가
  - [ ] `ProjectionVisual` 하위에 2개의 빈 게임오브젝트(`CheckPoint_Left`, `CheckPoint_Right`)를 끌 날 양끝 폭에 맞춰 배치
- [ ] **`ChiselTool.cs` 스크립트 수정 (Visual 업데이트 로직)**
  - [ ] `Update()`에서 끌 끝단 기준 앞쪽(`forward`)으로 Raycast 발사
  - [ ] 목재(`ChiselZone` 레이어) 표면에 닿으면 `ProjectionVisual`의 위치와 노멀(회전) 갱신
  - [ ] 거리가 특정 수치(예: 10cm) 이내일 때만 나타나도록 Alpha Fade 처리 (또는 SetActive)
- [ ] **`ChiselTool.cs` 스크립트 수정 (타격 유효성 2-Point 판정 로직)**
  - [ ] `HammerTool`로부터 타격을 전달받았을 때(`OnHammerHit`), 현재 나무 표면에 생성된 `CheckPoint_Left.position`과 `CheckPoint_Right.position` 위치 획득
  - [ ] `ChiselZone`의 `BoxCollider.bounds.Contains()`를 사용하여 두 점이 모두 사각형 폼 내부에 포함되었는지 검사
