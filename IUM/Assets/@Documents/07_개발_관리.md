## 2. 주요 미정 사항

다음 항목은 프로토타입 테스트 또는 팀 협의를 통해 결정해야 한다.

1.  오브젝트 잡기 허용 거리
2.  이동 방식과 회전 방식
3.  먹선 필요 개수
4.  먹매김 허용 위치·각도 오차
5.  톱질 유효 속도 범위
6.  절단면 평가 기준
7.  끌 타격 유효 속도
8.  홈의 목표 폭과 깊이
9.  부재 손상도 최대값
10. 도리 설치 스냅 거리
11. 도리 설치 스냅 각도
12. 스냅 즉시 고정 여부
13. 공포 퍼즐 부재 개수
14. 공포 퍼즐 설치 순서
15. 공정별 매우 우수·합격 기준
16. 노장 음성의 사전 녹음 여부
17. PTT 버튼 배치
18. 이음이 고정 힌트 문장
19. 실패 부재 최대 표시 개수
20. 프롤로그 최초 실행 건너뛰기 허용 여부

| 톱질          | 왕복 조작, 절단 진행, 결과 판정 가능  |
| 끌질          | 끌·망치 양손 조작과 홈 가공 가능      |
| 평가          | 동일 작업 결과에 동일 등급 출력       |

| Quest 테스트  | 전체 시나리오를 기기에서 완주 가능    |
