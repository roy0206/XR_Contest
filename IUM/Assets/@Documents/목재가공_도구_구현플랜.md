# 공포 목재 가공 도구 구현 플랜

## 작업 전체 흐름

```
원목
 │
 ▼ 먹매김 (InkLineTool)   → 절단선/기준선 표시
 │
 ▼ 톱질 (SawTool)         → Wood_Waste 제거 (폐자재 사라짐)
 │
 ▼ 대패질 (HandPlaneTool) → BlendShape "Planed" 0→100
 │
 ▼ 끌질 (ChiselTool)      → BlendShape "Chiseled" 0→100
 │
 ▼ 조립 (AssemblyTarget)
```

---

## 목재 오브젝트 구조 (공통)

```
Wood_Root  (Grabbable)
├── Wood_Main   (SkinnedMeshRenderer)
│     ├── BlendShape: "Planed"     ← 대패질 진행도
│     └── BlendShape: "Chiseled"   ← 끌질 진행도
└── Wood_Waste  (MeshRenderer)     ← 톱질 완료 시 SetActive(false)
```

- `Wood_Main`은 처음부터 **올바른 크기(절단 후 형태)**로 모델링
- `Wood_Waste`는 잘려나갈 부분을 별도 오브젝트로 겹쳐 놓음
- `VisualWoodModifier`가 두 오브젝트 모두 참조

---

## VisualWoodModifier 확장

기존 메서드는 그대로 유지, 아래 항목만 추가:

```
[Header("톱질 - 폐자재")]
public GameObject wasteObject

+ HideWaste()  → wasteObject.SetActive(false)
```

## 1. 톱질 (Saw)

### 인터랙션 방식
- `HandPlaneTool`과 동일한 **스트로크 판정** 구조
- **양방향** 허용 (앞뒤 모두 유효) — `angle <= tolerance || angle >= (180 - tolerance)` 체크

### 완료 시 처리
- `SawZone.CompleteWork()` → `woodModifier.HideWaste()` 호출
- `Wood_Waste.SetActive(false)` → 폐자재 사라짐
- BlendShape 없음 (Main 메시는 이미 올바른 형태)

### 채점 요소
| 요소 | 측정 방법 |
|---|---|
| 방향 각도 정확도 | `moveDir`과 `sawDirection`의 각도 오차 |
| 스트로크 속도 | `minCutSpeed` 대비 실제 속도 |
| 스트로크 횟수 | `requiredStrokes` 대비 실제 횟수 (적을수록 고득점) |

### 새 파일
- `SawTool.cs` — `HandPlaneTool` 구조 재사용, 양방향 로직
- `SawZone.cs` — `PlaneZone` 구조 재사용, `CompleteWork()`에 `HideWaste()` 추가

## 2. 끌질 (Chisel)

### 인터랙션 방식 — "망치로 타격하기" (기획 문서 F-009 반영)
1. 한 손으로 끌을 잡고 `ChiselZone`(먹선 안쪽 가공 영역)에 끌 끝을 위치
2. 다른 손으로 망치(`HammerTool`)를 잡음
3. 망치로 끌 머리(헤드)를 타격
4. 타격 속도와 방향, 끌 각도를 판정하여 유효 타격 시 BlendShape 한 단계 진행

### 타격 판정 및 가공 진행
- 망치의 속도(`hammerVelocity.magnitude`)가 유효 범위(`minHitSpeed` ~ `maxHitSpeed`) 내인지 판정
- 망치의 타격 방향과 끌의 진행 방향 간의 각도 오차 판정

### 위치 및 정렬 판정 (2-Point 양끝단 검사)
- **방식:** 끌의 날(Blade) 양 끝단에 위치한 두 개의 검사 포인트(또는 콜라이더)가 모두 가공 목표 영역(사각형 `ChiselZone`) 내부에 포함되어 있는지 확인합니다.
- **효과:** 두 점이 모두 사각형 영역 안에 있다면, 끌의 위치가 정확할 뿐만 아니라 사각형의 변과 나란히 **올바른 회전 각도**로 정렬되어 있음을 기하학적으로 완벽히 보장할 수 있습니다. 
- 직관적이고 계산이 단순하며, 플레이어가 조금이라도 삐딱하게 대면 둘 중 한 점이 밖으로 나가버려 자연스럽게 가공이 제한됩니다.

### 가공 깊이(depth) 연산
- `depth`는 타격 속도와 끌의 세워진 각도, 그리고 2-Point 정렬 상태에 따라 가변 적용됩니다.
- 타격마다 `ChiselZone.AddHitProgress(float depth)` 호출
- 누적 `depth`가 임계값 도달 시 `"Chiseled"` BlendShape 증가

### 끌 각도 — 가공 깊이와 채점에 영향
```
끌 각도 = Angle(-chiselTip.forward, surfaceNormal)
  → 적정 각도(예: 30~45도)일 때 가장 효과적으로 파임
  → 너무 세우면 깊이 패이지만 앞으로 안 나감
  → 너무 눕히면 헛스윙 처리
```

### BlendShape 진행 (단계 증가 방식)
- 누적된 `depth`가 `depthPerStep` 도달할 때마다 BlendShape를 `1/totalSteps`씩 증가
- 시각적으로 점진적으로 홈이 파이는 것을 표현

### 채점 요소 (기획 문서 기준)
| 요소 | 측정 방법 |
|---|---|
| 타격 속도 적정도 | 약한 타격 / 적정 타격 / 강한 타격(초과 깊이) 비율 |
| 타격 방향 정확도 | 망치 궤적과 끌의 일치도 |
| 끌 위치/방향 정확도 | 끌 날 양끝단의 2-Point(또는 콜라이더)가 사각형(ChiselZone) 내부에 모두 포함되는지 여부 |
| 홈 깊이 및 위치 | 최종 완료 시 목표치 대비 오차 |

### 시각적 가이드 (끌 투영 피드백)
- **목적:** 플레이어가 끌을 나무에 갖다 댈 때, 실제로 파이게 될 위치와 형태를 직관적으로 인지하도록 보조.
- **구현 방식:** 
  1. `ChiselTool` 끝단(Tip)에서 전방으로 Raycast를 쏘아 목재 표면을 감지.
  2. 교차점에 끌 단면 모양의 반투명 그래픽(Decal Projector 또는 Quad Mesh)을 표면의 노멀(Normal) 방향에 맞춰 사영(투영).
  3. 끌의 회전(Roll)에 따라 투영 이미지도 함께 회전하여, 플레이어가 먹선(가이드라인)에 정확히 각도를 맞출 수 있도록 유도.
  4. 일정 거리(예: 10cm) 이내로 접근했을 때 서서히 나타나도록(Alpha Fade) 처리하여 자연스러운 연출.

### 새 파일
- `ChiselTool.cs` — Zone 진입/이탈, 망치 충돌 감지(`OnHammerHit`), 각도 계산
- `HammerTool.cs` — IWoodTool 구현 (단순 충돌 및 속도 전달용)
- `ChiselZone.cs` — 누적 깊이 판정 → 단계 진행도, BlendShape 연동

## 3. 먹매김 (InkLine) 채점 확장

기존 `InkLineTool` / `InkLineZone` 코드는 유지,  
`InkLineZone`에 **목표 라인 정보**만 추가:

```
[Header("채점용 목표 라인")]
public Transform targetStart   ← 이상적인 시작점
public Transform targetEnd     ← 이상적인 끝점
```

### 채점 요소
| 요소 | 측정 방법 |
|---|---|
| 시작점 위치 정확도 | `Distance(pinnedStartPos, targetStart.position)` |
| 끝점 위치 정확도 | `Distance(pinnedEndPos, targetEnd.position)` |
| 장력 충분도 | `pullDistance / maxPullDistance` 비율 |

- 스냅 순간(`OnInkLineSnapped`) 3요소 계산 → `qualityScore` 산출

---

## 채점 구조 (공통)

각 `WorkZone`이 완료 시 `float qualityScore(0~1)`를 산출:

```
먹매김 점수 = 위치정확도(시작+끝 평균) × 장력충분도
톱질   점수 = 방향각도 정확도 × 속도 적정도
대패질 점수 = 방향각도 정확도 × 속도 적정도
끌질   점수 = 타격 적정도(속도, 방향) × 끌 위치/방향 정확도
```

- `WorkZone.CompleteWork(float qualityScore)`로 AI 평가 시스템에 전달
- 기존 코드 호환을 위해 별도 `event Action<float> WorkCompleted` 이벤트로 분리 권장

## 아트 담당자 전달용 요약

**[목재 모델 구조 가이드]**

1. **오브젝트 구성**
   - **`Wood_Main`**: SkinnedMeshRenderer (완성된 형태 기준)
   - **`Wood_Waste`**: 일반 MeshRenderer (톱질로 잘려나갈 부분, 톱질 후 Hide 처리됨)
   - 두 오브젝트는 같은 위치에 겹쳐서 배치해 주세요.

2. **BlendShape 설정 (Wood_Main에 적용)**
   - `"Planed"`: 대패질을 하면서 깎여나가는 형태 (0~100)
   - `"Chiseled"`: 끌질을 하면서 홈(장부)이 파이는 형태 (0~100)

3. **필요한 수치 정보 (개발팀 전달 요망)**
   - 원목의 전체 크기 (특히 `Wood_Waste`의 절단 위치)
   - 끌질로 파야 하는 홈(장부)의 중심 위치와 크기(가로, 세로, 깊이)
   - 먹매김을 해야 하는 목표 라인의 시작점(Start)과 끝점(End)의 위치 좌표
