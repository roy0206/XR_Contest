# PROJECT 이음 - 오브젝트·부재·가공

## 1. F-005 컨트롤러 기반 오브젝트 잡기 및 놓기

### 1.1 기능 정의

플레이어가 컨트롤러로 도구와 부재를 잡고 이동하거나 내려놓는 공통 기능이다.

### 1.2 잡을 수 있는 대상

- 먹줄
- 톱
- 끌
- 망치
- 가공 전 부재
- 가공 중 부재
- 공포 퍼즐 부재

설치 완료된 부재와 노장 오브젝트는 잡을 수 없다.

### 1.3 시작 조건

- 오브젝트가 잡기 가능 상태
- 컨트롤러가 정상 추적 중
- 플레이어가 강제 연출 상태가 아님
- 컨트롤러와 오브젝트 사이 거리가 잡기 허용 범위 이내

### 1.4 정상 흐름

컨트롤러가 오브젝트에 접근  
↓  
오브젝트 테두리 강조  
↓  
그립 버튼 누름  
↓  
오브젝트가 손의 잡기 지점에 결합  
↓  
컨트롤러 이동에 따라 오브젝트 이동  
↓  
그립 버튼 놓음  
↓  
현재 위치에 오브젝트 배치

### 1.5 잡기 강조

잡기 가능 거리 안에 들어오면 다음 피드백을 제공한다.

- 오브젝트 외곽선 표시
- 약한 밝기 변화
- 컨트롤러에 짧은 진동
- 잡을 수 없는 경우 강조하지 않음

### 1.6 양손 사용

- 양손에 각각 하나의 도구를 잡을 수 있다.
- 먹줄은 양 끝의 줄을 고정한 후에 줄 튕기기가 가능하다.
- 끌질에서는 한 손에 끌, 다른 손에 망치를 잡는다.

### 1.7 컨트롤러 추적 유실

컨트롤러 추적이 일시적으로 끊긴 경우:

1.  도구의 마지막 유효 위치와 회전을 유지한다.
2.  1초 이내 추적 복구 시 다시 컨트롤러에 결합한다.
3.  1초 이상 복구되지 않으면 도구를 컨트롤러에서 분리한다.
4.  접근 불가능한 위치에 놓이면 복구 규칙을 적용한다.

실제 유지 시간은 기기 테스트 후 조정한다.

### 1.8 종료 상태

오브젝트는 다음 중 하나의 상태여야 한다.

- 플레이어가 잡고 있음
- 유효한 작업 공간에 놓여 있음
- 작업대 원위치
- 설치 위치에 고정됨
- 배운 흔적 공간에 배치됨

## 2. F-006 작업 부재 및 새 재료 관리

### 2.1 기능 정의

플레이어가 가공할 목재 부재를 지급하고, 실패한 부재와 새로운 부재를 관리하는 기능이다.

### 2.2 부재 상태

| **상태**  | **설명**                     |
|-----------|------------------------------|
| 대기      | 아직 작업하지 않은 부재      |
| 작업 중   | 현재 공정이 진행 중인 부재   |
| 공정 완료 | 현재 공정을 통과한 부재      |
| 가공 실패 | 허용 손상 범위를 초과한 부재 |
| 설치 완료 | 최종 위치에 고정된 부재      |

### 2.3 새 재료 지급

새 재료는 다음 상황에 지급한다.

- 공정 시작
- 기존 부재가 가공 실패 상태가 됨
- 플레이어가 노장에게 새 재료 요청
- 플레이어가 재료 지급 위치에서 신규 부재 선택
- 오류로 부재 상태를 복원할 수 없음

새 재료 횟수에는 제한을 두지 않는다.

### 2.4 배운 흔적 연출

가공 실패 부재는 삭제하지 않고 작업대 옆의 지정 공간에 배치한다.

- 실패 부재는 다시 작업할 수 없다.
- 실패한 흔적이 시각적으로 남는다.
- 부재 수가 지나치게 많아지면 최대 표시 개수를 설정할 수 있다.
- 최대 개수 초과 시 오래된 부재를 정리하되, 연출상 사라지는 장면을 사용한다.

리소스의 절약을 위해 연출을 유지할 것인지는 팀원간 상의 필요

## 3. F-007 먹매김 시스템

### 3.1 기능 정의

플레이어가 먹줄을 사용하여 도리 가공에 필요한 기준선을 목재 표면에 표시하는 기능이다.

### 3.2 시작 조건

- Chapter 1 먹매김 공정 활성화
- 대상 부재가 작업대에 배치됨
- 먹줄 도구 사용 가능
- 노장의 공정 설명 완료
- 목표 먹선 데이터가 로드됨

### 3.3 도구 구성

먹매김 도구는 XR 조작에 맞게 단순화한다.

- 먹줄 본체
- 줄
- 줄 끝 고정부
- 줄을 들어 올려 튕길 수 있는 상호작용 지점

### 3.4 정상 흐름

먹줄 잡기  
↓  
줄 끝을 목재의 첫 고정점에 배치  
↓  
첫 고정점 활성화  
↓  
반대편 고정점까지 줄을 당겨서 고정하기  
↓  
줄 장력 조건 충족  
↓  
다른 손으로 줄 중앙을 잡음  
↓  
줄을 위로 들어 올림  
↓  
그립 버튼 놓기  
↓  
줄이 목재 표면을 타격  
↓  
두 고정점 사이에 먹선 생성  
↓  
먹선 데이터 기록

### 3.5 고정점 처리

줄 끝이 목재의 유효 표면에 접근하면 고정 후보 표시가 나타난다.

- 유효 표면: 파란색 또는 흰색 표시
- 목재 밖: 표시 없음
- 고정 가능 범위에 들어오면 약한 스냅 적용
- 고정 후에는 줄 끝이 표면에 붙어 유지됨

### 3.6 장력 판정

먹줄이 충분히 팽팽해야 선이 생성된다.

장력 판정 요소:

- 두 고정점 사이 거리
- 줄의 늘어난 길이
- 줄 중앙의 흔들림
- 줄이 목재 표면 위에 위치하는지 여부

장력이 부족하면 선을 생성하지 않는다.

노장 대사 예시:

“줄을 조금 더 팽팽히 당겨 보거라.”

### 3.7 먹선 생성

유효한 상태에서 줄을 튕기면 다음을 수행한다.

- 목재 표면에 먹선 표시
- 먹줄 튕김 효과음
- 작은 먹가루 효과
- 컨트롤러 진동
- 먹선 시작점과 끝점 기록
- 목표선 대비 오차 계산

### 3.8 잘못 그은 선

잘못 그은 먹선은 새 목재를 받아 다시 그어야 한다.

이 때 그어둔 모든 목선을 초기화 하고 새로 시작할 것인지 직전 시행만 재시행하는지는 협의하여야 한다.

전체 선을 그은 횟수를 기록한다

### 3.9 판정 요소

- 시작점 위치 오차
- 끝점 위치 오차

### 3.10 제안 판정 기준

| **결과**  | **평균 위치 오차** | **각도 오차** |
|-----------|--------------------|---------------|
| 매우 우수 | 3mm 이하           | 2도 이하      |
| 합격      | 3mm 초과 10mm 이하 | 5도 이하      |
| 불합격    | 10mm 초과          | 5도 초과      |

수치는 실제 XR 조작 난이도에 따라 조정한다.

### 3.11 실패 처리

#### 한쪽 끝이 고정되지 않은 상태

- 먹선 생성 안 됨
- 짧은 실패 효과음
- 노장 안내

#### 장력이 부족한 상태

- 먹선 생성 안 됨
- 줄이 약하게 흔들림
- 장력 안내

#### 목재 표면 밖으로 선 생성 시도

- 해당 구간은 무효 처리

### 3.12 종료 조건

필요한 먹선을 모두 생성하고 평가 요청 상태가 되었을 때 종료한다.

종료 후 다음 데이터가 남는다.

- 유효 먹선 (합격 이상의 먹선 수)
- 잘못 그은 선 개수(전체 그은 선 – 필수 선 개수)
- 위치 오차
- 각도 오차
- 소요 시간
- 시도 횟수
- 최종 평가

## 4. F-008 톱질 시스템

### 4.1 기능 정의

플레이어가 먹선을 기준으로 목재를 절단하는 기능이다.

### 4.2 시작 조건

- 먹매김 공정 완료
- 유효 먹선 존재
- 대상 부재가 톱질 작업대에 고정됨
- 톱 사용 가능
- 노장 설명 완료

### 4.3 정상 흐름

톱 잡기  
↓  
톱날을 먹선 근처에 배치  
↓  
절단 시작 허용 영역 진입  
↓  
톱을 앞뒤로 왕복  
↓  
유효 왕복 동작 판정  
↓  
절단 깊이 증가  
↓  
톱밥 생성  
↓  
목재 바닥까지 절단  
↓  
불필요한 목재 부분 분리  
↓  
절단면 평가

### 4.4 절단 시작 허용 영역

먹선 주변에 보이지 않는 허용 영역을 설정한다.

- 허용 영역 안에서만 초기 홈 생성 가능
- 허용 영역 밖에서 톱질하면 목재가 즉시 손상되지 않음
- 톱이 먹선 근처가 아니라는 안내를 먼저 제공
- 일정 깊이 이상 잘못된 위치를 절단했을 때만 손상 처리

### 4.5 유효 톱질 판정

다음 조건을 모두 고려한다.

- 톱날과 목재의 접촉
- 톱날 이동 거리
- 이동 방향
- 이동 속도
- 먹선 방향과 톱날 방향의 정합도
- 톱날 기울기
- 연속 왕복 여부

너무 짧거나 빠른 손떨림은 유효 톱질로 인정하지 않는다.

### 4.6 절단 진행량

절단 진행량은 다음 요소를 기반으로 계산한다.

- 유효 이동 거리
- 접촉 시간
- 이동 속도 보정
- 방향 정합도
- 톱날 기울기 보정

한 번의 입력마다 고정된 두께를 제거하는 방식은 사용하지 않는다.

### 4.7 시각 및 촉각 피드백

- 절단 깊이에 따라 홈이 깊어짐
- 톱밥 파티클 발생
- 톱질 효과음 반복
- 유효 톱질 시 약한 진동
- 먹선 이탈 시 톱질 소리 변화
- 절단 완료 시 목재 분리음

### 4.8 판정 데이터

- 절단선 위치 오차
- 절단면 각도 오차
- 절단면 평탄도
- 초과 절단 깊이
- 먹선 밖 절단 길이
- 부재 손상도
- 유효 왕복 횟수
- 소요 시간

### 4.9 실패 조건

다음 조건 중 하나를 충족하면 부재를 가공 실패 상태로 처리한다.

- 절단선이 허용 범위를 크게 벗어남
- 절단면 기울기가 한계 이상
- 제거하면 안 되는 부위를 완전히 절단함
- 초과 절단 깊이가 한계 이상
- 부재 손상도가 최대치를 초과함

노장 대사 예시:

“먹선이 정확해도 톱이 벗어나면 그 부재는 쓸 수 없단다.”

### 4.10 종료 조건

- 목표 부위 절단 완료
- 절단 결과 판정 완료
- 합격 이상이면 끌질 공정으로 이동
- 불합격이면 실패 단계별 지원 후 새 부재 지급

새 부재로 재시작할 경우 톱질부터 다시 수행한다.

## 5. F-009 끌질 시스템

### 5.1 기능 정의

플레이어가 끌과 망치를 사용하여 먹선 안쪽에 결구용 홈을 가공하는 기능이다.

### 5.2 시작 조건

- 톱질 공정 통과
- 대상 부재가 끌질 작업대에 고정됨
- 끌과 망치 사용 가능
- 목표 홈 위치와 깊이 데이터 존재
- 노장 설명 완료

### 5.3 기본 조작

- 한 손으로 끌을 잡는다.
- 끌날을 먹선 안쪽에 배치한다.
- 다른 손으로 망치를 잡는다.
- 망치로 끌 머리를 타격한다.
- 끌을 기울이거나 이동해 잘린 목재 조각을 제거한다.

### 5.4 정상 흐름

끌 잡기  
↓  
망치 잡기  
↓  
끌날을 목표 영역에 배치  
↓  
끌 방향 확인  
↓  
망치로 끌 머리 타격  
↓  
타격 속도와 방향 판정  
↓  
끌날 방향으로 목재 가공  
↓  
목재 파편 생성  
↓  
끌 위치 이동  
↓  
반복 작업  
↓  
목표 깊이와 폭 도달  
↓  
홈 평가

### 5.5 유효 타격 판정

유효 타격 조건:

- 망치 머리가 끌 머리와 충돌
- 망치 속도가 최소 기준 이상
- 망치 속도가 최대 안전 기준 이하
- 타격 방향이 끌의 진행 방향과 일정 범위 이내
- 끌날이 목재 표면에 닿아 있음
- 끌날이 유효 가공 영역 안에 있음

### 5.6 가공 깊이

1회 타격으로 발생하는 가공 깊이는 다음 요소에 영향을 받는다.

- 망치 속도
- 충돌 방향
- 끌 각도
- 목재와의 접촉 상태
- 현재 홈 깊이
- 가공 영역 경계와의 거리

과도한 타격은 홈 깊이 초과와 부재 손상으로 이어진다.

### 5.7 목재 제거

- 타격으로 절삭 경계 생성
- 끌을 기울이면 목재 조각 분리
- 목재 파편과 끌밥 효과 표시
- 홈 내부 형상 갱신
- 실제 메시 변형이 어렵다면 단계별 모델 교체 또는 셰이더 표현 사용

### 5.8 잘못된 조작

#### 먹선 바깥에 끌 배치

- 첫 타격 전에는 가공 진행을 막음
- 끌 위치 안내 표시
- 반복 시 노장 안내

#### 먹선 밖을 실제로 가공

- 경계 손상도 증가
- 손상도가 한계를 넘으면 부재 실패

#### 끌이 반대 방향

- 유효 가공 처리 안 함
- 컨트롤러 진동과 안내 표시

#### 망치로 목재 직접 타격

- 가공 진행 없음
- 타격음만 재생
- 반복 시 안내 대사

#### 타격이 너무 약함

- 끌이 거의 들어가지 않음
- 약한 타격음
- 노장 안내 가능

#### 타격이 너무 강함

- 깊이가 크게 증가
- 부재 손상도 증가
- 강한 진동과 목재 파손 효과

### 5.9 판정 데이터

- 홈 위치 오차
- 홈 폭 오차
- 홈 깊이 오차
- 홈 벽면 각도
- 경계선 손상량
- 초과 가공량
- 부재 손상도
- 유효 타격 횟수
- 잘못된 타격 횟수
- 소요 시간

### 5.10 종료 조건

- 목표 홈의 폭과 깊이를 충족
- 손상도가 허용 범위 이내
- 공정 평가 완료

합격 이상이면 Chapter 1 완료 상태로 전환한다.
