# 2026-08-12 · 대사 데이터 변환 · 영상 컷씬

## 세션 범위

두 가지를 했다.

1. `Assets/@Documents/대사/`의 흐름도 이미지 3장(프롤로그·튜토리얼 / Chapter 1 도리 제작 / Chapter 2 도리 설치)에 있던 대사를 `dialogue.json`으로 옮겼다. 시퀀스 9개 → 37개, 대사 줄 107개.
2. mp4 컷씬 재생 경로를 추가했다. 기존 컷씬은 씬을 겹쳐 올려 `CutsceneStage`가 연출하는 방식뿐이었다.

수정: `Assets/@AddressableAssets/Data/Static/dialogue.json`, `cutscene.json`, `Assets/@Scripts/Cutscene/CutsceneModels.cs`, `CutsceneDirector.cs`, `CutsceneDebugController.cs`, 신규 `CutsceneVideoSurface.cs`.

기록 규칙은 [00 기록 규칙](00_기록_규칙.md)을 따른다.

## 대사 ID 규약

공정 러너가 붙을 자리를 먼저 정해 두기 위해 평가 분기를 정규화했다. 이미지의 분기는 `적합도 미만` / `적합도 합격 + 90% 미만` / `적합도 합격 + 90% 이상` 세 갈래이고, 이를 `ProcessGrade`에 그대로 대응시켰다.

| 이미지 분기 | ID 규약 | ProcessGrade |
|---|---|---|
| 적합도 미만 | `{공정}_result_fail` | `Fail` |
| 90% 미만 | `{공정}_result_pass` | `Pass` |
| 90% 이상 | `{공정}_result_excellent` | `Excellent` |

공정 설명은 `{공정}_intro`다. 러너는 "진입 시 `{공정}_intro`, 평가 후 `{공정}_result_{등급}`" 두 줄로 대사를 붙일 수 있다.

`ProcessGrade.Assisted`(도움 완료)에 해당하는 대사는 이미지에 없어 만들지 않았다. 씬이 참조하는 ID(`prologue_nojang`, `ending_nojang`, `ending_ieumi`)는 텍스트만 갈고 ID는 보존했다. 씬 파일은 수정하지 않았다.

## 영상 컷씬을 씬으로 만들지 않은 이유

`CutsceneModels.cs`의 기존 주석은 연출을 데이터가 아니라 씬에 두는 근거를 적고 있다 — JSON의 단계 목록은 씬 오브젝트를 참조할 수 없고 미리보기도 안 된다. mp4에는 그 근거가 적용되지 않는다. 연출할 씬 오브젝트가 없기 때문이다.

영상 한 편마다 빈 씬을 만들면 씬 파일 + Build Settings 등록이 붙는다. Build Settings는 공용 자산이라 영상이 추가될 때마다 승인이 필요해진다. 그래서 `CutsceneDefinition.Video` 한 줄로 끝나게 했다.

`scene`과 `video`를 함께 적으면 둘 다 올라간다. 이때 끝나는 시점은 스테이지가 정한다. 스테이지 없는 씬 + 영상 조합은 배경으로 성립하므로 경고만 남기고 진행한다.

## 검증하지 못한 것

영상 컷씬은 컴파일과 실제 재생을 확인하지 못했다. 이 세션에서 Unity를 실행하지 않았고 프로젝트에 테스트할 mp4가 아직 없다. 확인한 것은 JSON 파싱과 코드 구조 정합성뿐이다.

Quest에서 `jar:file://` 경로 재생과 스테레오 렌더링 시 영상 표면의 가독성·거리감은 실기기 검증 항목이다. ISSUE-007(컷씬 카메라 교체의 VR 안전성)과 같은 성격이다.
