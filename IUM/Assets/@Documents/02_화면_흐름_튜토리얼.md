## 1. F-001 메인 화면

### 1.1 기능 정의

게임 실행 후 플레이어가 게임 시작, 이어하기, 옵션 기능을 선택할 수 있는 최초 화면이다.

### 1.2 진입 조건

- 게임 애플리케이션 실행 완료
- 필수 시스템 초기화 완료
- 로컬 저장 데이터 확인 완료
- XR 컨트롤러 연결 상태 확인 완료

### 1.3 화면 구성

메인 화면에는 다음 세 가지 메뉴를 표시한다.

게임 시작

이어하기

옵션

타이틀 로고와 간단한 작업장 배경을 함께 표시할 수 있다.

### 1.4 게임 시작

#### 기능

새 게임을 시작한다.

#### 정상 흐름

게임 시작 선택  
↓  
기존 저장 데이터 확인  
↓  
저장 데이터 없음  
↓  
프롤로그 실행

기존 저장 데이터가 존재하는 경우 확인 창을 표시한다.

기존 진행 기록이 있습니다.

새 게임을 시작하면 이전 진행 기록이 초기화됩니다.

\[새로 시작\] \[취소\]

플레이어가 새로 시작을 확정하면 기존 진행 정보를 초기화하고 프롤로그부터 시작한다.

옵션 데이터는 초기화하지 않는다.

### 1.5 이어하기

#### 기능

하드웨어 내부에 저장된 진행 정보에서 게임을 재개한다.

#### 조건

유효한 로컬 저장 데이터가 존재해야 한다.

#### 저장 데이터가 있는 경우

- 이어하기 버튼을 활성화한다.
- 선택 시 저장된 공정의 시작 지점으로 이동한다.
- 작업 도중의 세부 가공 상태는 복원하지 않는다.
- 마지막으로 완료하지 못한 공정의 처음부터 다시 시작한다.

예시:

저장된 상태: 먹매김 완료, 톱질 미완료  
↓  
이어하기  
↓  
톱질 공정 시작 지점

#### 저장 데이터가 없는 경우

- 이어하기 버튼을 비활성화한다.
- 선택 불가능한 상태임을 시각적으로 표시한다.
- 버튼을 가리키면 “저장된 진행 정보가 없습니다.” 문구를 표시할 수 있다.

### 1.6 옵션

옵션 버튼을 선택하면 옵션 화면을 연다.

옵션 화면에서 메인 화면으로 돌아갈 수 있는 뒤로 가기 버튼을 제공한다.

### 1.7 UI 조작

- 컨트롤러 레이로 버튼을 가리킨다.
- 가리킨 버튼은 밝기 또는 크기가 약간 변화한다.
- 트리거 입력으로 버튼을 선택한다.
- 버튼 선택 시 짧은 효과음을 재생한다.

### 1.8 예외 처리

#### 컨트롤러가 연결되지 않은 경우

- “컨트롤러 연결을 확인해 주세요.” 안내 표시
- 입력 복구 전까지 메뉴 선택 제한

#### 저장 데이터가 손상된 경우

- 이어하기 비활성화
- “저장 정보를 불러오지 못했습니다. 새 게임으로 시작해 주세요.” 표시
- 옵션 데이터는 별도로 복구 시도

### 1.9 종료 상태

선택에 따라 다음 중 하나로 이동한다.

- 프롤로그
- 저장된 공정
- 옵션 화면

## 2. F-002 옵션 시스템

### 2.1 기능 정의

게임 내 음량을 플레이어가 직접 조정하는 기능이다.

### 2.2 옵션 항목

| **옵션**  | **기능**                             |
|-----------|--------------------------------------|
| 음악 볼륨 | 배경음악 크기 조정                   |
| 대사 볼륨 | 노장 및 이음이의 목소리 크기 조정    |
| 환경 볼륨 | 바람, 톱질, 망치, 작업장 효과음 조정 |
| 영상 볼륨 | 영상 컷씬 재생 음량 조정             |

각 볼륨은 0~100 범위로 설정한다.

### 2.3 정상 흐름

옵션 진입  
↓  
볼륨 슬라이더 선택  
↓  
스틱 또는 컨트롤러 이동으로 값 변경  
↓  
변경된 소리를 즉시 미리 듣기  
↓  
뒤로 가기  
↓  
설정 자동 저장

### 2.4 볼륨 분류

#### 음악 볼륨

적용 대상:

- 메인 화면 음악
- 프롤로그 배경음악
- 작업장 배경음악
- 엔딩 음악

#### 대사 볼륨

적용 대상:

- 노장 음성
- 이음이 TTS 음성
- 프롤로그 내레이션
- 튜토리얼 음성 안내

#### 환경 볼륨

적용 대상:

- 바람 소리
- 작업장 소음
- 먹줄 튕기는 소리
- 톱질 소리
- 톱밥 효과음
- 망치 타격음
- 끌질음
- 목재 충돌음
- 부재 설치음
- UI 효과음

UI 효과음을 환경 볼륨과 분리할지는 추후 확장 사항으로 둔다.

#### 영상 볼륨

적용 대상:

- 영상(mp4) 컷씬의 재생 음량 전체

영상 파일은 배경음악, 내레이션, 효과음이 이미 하나로 믹스되어 있어 위 세 분류로 나눌 수 없다. 분리 재생 대신 항목을 하나 늘려 영상 구간 전체를 한 슬라이더로 조절한다.

인게임 연출로 진행하는 컷씬은 이 항목의 대상이 아니다. 그쪽 소리는 대사 볼륨과 환경 볼륨을 그대로 따른다.

### 2.5 저장

옵션 변경 즉시 로컬 설정 파일에 저장한다.

게임 진행 데이터가 없더라도 옵션 데이터는 유지한다.

새 게임 시작 시에도 옵션은 초기화하지 않는다.

### 2.6 기본값

| **옵션**  | **기본값** |
|-----------|------------|
| 음악 볼륨 | 70         |
| 대사 볼륨 | 100        |
| 환경 볼륨 | 80         |
| 영상 볼륨 | 100        |

실제 기본값은 기기 테스트를 통해 조정한다.

## 3. F-003 프롤로그 시스템

### 3.1 기능 정의

숭례문 화재와 전통 기술 계승의 필요성을 전달하고 플레이어를 복원 현장으로 이동시키는 도입 연출이다.

### 3.2 시작 조건

- 새 게임 선택
- 프롤로그 다시 보기 선택
- 필수 리소스 로딩 완료

### 3.3 정상 흐름

화면 암전  
↓  
2008년 2월 10일 자막  
↓  
숭례문 화재 장면 또는 뉴스 영상  
↓  
무너지는 건축물과 화염 연출  
↓  
노장의 목소리  
↓  
“건물은 다시 세울 수 있습니다.”  
↓  
“하지만 기술은 사람이 없으면 이어지지 않습니다.”  
↓  
화면 암전  
↓  
2008년 숭례문 복원 현장으로 전환  
↓  
조작 튜토리얼

### 3.4 입력 제한

프롤로그 재생 중에는 다음 입력을 제한한다.

- 이동
- 오브젝트 잡기
- 이음이 질문
- NPC 상호작용
- 공정 진행

일시정지 메뉴와 프롤로그 건너뛰기만 허용할 수 있다.

### 3.5 건너뛰기

- 컨트롤러의 지정 버튼을 길게 누르면 건너뛰기 게이지가 표시된다.
- 2초 이상 유지하면 프롤로그를 종료한다.
- 즉시 튜토리얼 장면으로 이동한다.
- 프롤로그 완료 여부는 저장한다.

최초 플레이에서 건너뛰기를 허용할지는 팀 협의 후 결정한다.

### 3.6 예외 처리

영상 재생에 실패한 경우:

- 정지 이미지와 자막을 이용한 대체 연출 사용
- 음성 내레이션은 계속 재생
- 프롤로그가 끝난 뒤 정상적으로 튜토리얼 이동

## 4. F-004 조작 튜토리얼

### 4.1 기능 정의

플레이어가 게임에 필요한 기본 컨트롤러 조작을 이음이의 지도하에 학습하는 기능이다.

### 4.2 학습 항목

1.  주변 바라보기
2.  이동
3.  회전
4.  오브젝트 가리키기
5.  도구 잡기
6.  도구 놓기
7.  PTT 버튼으로 이음이 호출하기

### 4.3 정상 흐름

튜토리얼 시작  
↓  
이음이 인사  
↓  
도구 강조 표시  
↓  
도구 잡기  
↓  
지정 위치에 도구 놓기  
↓  
PTT 버튼 사용  
↓  
튜토리얼 완료  
↓  
Chapter 1 시작

### 4.4 튜토리얼 판정

각 동작은 성공 조건을 충족해야 다음 단계로 진행한다.

예시:

- 잡기: 지정 도구를 1초 이상 유지
- 놓기: 지정 영역 안에 도구 배치
- PTT: 버튼을 누르고 지정 문장 발화 또는 음성 입력 감지

### 4.5 실패 처리

일정 시간 동안 동작이 없으면 단계별 추가 안내를 제공한다.

- 5초: UI 아이콘 강조
- 10초: 이음이 음성 재안내
- 20초: 컨트롤러 위치와 버튼을 시각적으로 표시

튜토리얼에서는 불합격 판정을 사용하지 않는다.

## 5. F-014 Chapter 1 진행 관리

### 5.1 기능 정의

먹매김, 톱질, 끌질을 순차적으로 진행하고 각 공정 상태를 관리하는 기능이다.

### 5.2 진행 순서

Chapter 1 시작  
↓  
먹매김  
↓  
먹매김 평가  
↓  
톱질  
↓  
톱질 평가  
↓  
끌질  
↓  
끌질 평가  
↓  
도리 제작 완료  
↓  
Chapter 2

### 5.3 공정 잠금

- 이전 공정이 완료되기 전에는 다음 도구를 사용할 수 없다.
- 비활성 도구는 잡기 불가능 상태로 둔다.
- 해당 공정에서 사용하는 도구만 강조한다.
- 노장의 설명 종료 전에는 작업 판정을 시작하지 않는다.

### 5.4 Chapter 1 완료 상태

다음 데이터가 저장된다.

- 먹매김 최고 평가
- 톱질 최고 평가
- 끌질 최고 평가
- 공정별 시도 횟수
- 도움 완료 여부
- 사용한 부재 수
- 총 소요 시간

## 6. F-021 엔딩 시스템

### 6.1 기능 정의

완성된 숭례문과 복원 결과를 보여주고 기술 계승의 의미를 전달하는 마무리 연출이다.

### 6.2 시작 조건

- 공포 퍼즐 완료
- Chapter 2 평가 완료
- 필수 엔딩 리소스 로드 완료

### 6.3 정상 흐름

공포 조립 완료  
↓  
화면 전환  
↓  
복원된 숭례문 모습  
↓  
플레이어가 제작한 부재 강조  
↓  
노장 마지막 대사  
↓  
이음이 짧은 마무리  
↓  
최종 문구 표시  
↓  
메인 화면으로

### 6.4 최종 메시지

기술은 기록으로 남을 수 있지만,  
전통은 사람이 이어갈 때 비로소 살아남는다.

### 6.5 결과 표시

경쟁형 점수표 대신 다음 정보를 표시한다.

- 완료한 공정
- 공정별 최고 평가
- 도움 완료 여부
- 잘 수행한 작업
- 배운 전통 기술

총점과 순위는 표시하지 않는다.
