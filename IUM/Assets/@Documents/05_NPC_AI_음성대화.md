# PROJECT 이음 - NPC·AI·음성 대화

## 1. F-011 노장 NPC 시스템

### 1.1 기능 정의

노장이 공정을 설명하고, 작업을 지시하며, 결과를 평가한다.

### 1.2 노장의 역할

- 프롤로그 핵심 대사
- 챕터 도입 설명
- 공정 목적 설명
- 조작 주의사항 안내
- 공정 시작 지시
- 작업 결과 평가
- 엔딩 메시지 연결

### 1.3 대사 방식

노장의 대사는 원칙적으로 고정 스크립트를 사용한다.

- 대사 내용의 일관성 유지
- 역사적·기술적 오류 방지
- 응답 지연 방지
- 감정 연기 품질 확보

음성은 사전 녹음을 우선한다.

사전 녹음이 어려운 경우 지정된 TTS 음성을 사용할 수 있다.

### 1.4 노장 대사 재생 중

- 필수 공정 입력 잠금
- 이음이 PTT 입력 잠금
- 자막 표시
- 노장을 바라보도록 강제하지 않음
- 대사 종료 후 작업 입력 활성화

## 2. F-012 이음이 AI 시스템

### 2.1 기능 정의

이음이는 플레이어의 질문에 답하고, 현재 작업의 원리와 전통 목조건축 지식을 설명하는 생성형 AI 기반 학습 도우미다.

### 2.2 역할 제한

이음이는 다음 역할을 수행한다.

- 현재 공정 원리 설명
- 도구 사용법 설명
- 실패 원인에 대한 보조 설명
- 전통 목조건축 용어 설명
- 숭례문 복원과 기술 계승 의미 설명
- 생각을 유도하는 힌트 제공

이음이는 다음 역할을 수행하지 않는다.

- 플레이어 대신 작업 수행
- 합격 여부 결정
- 노장의 공정 지시 변경
- 게임 상태 변경
- 저장 데이터 임의 수정
- 근거 없는 역사적 사실 생성

### 2.3 응답 근거

이음이는 다음 자료를 우선하여 응답한다.

- 현재 공정 설명 데이터
- 사전에 정리한 목조건축 용어 자료
- 장인 인터뷰 자료
- 숭례문 복원 관련 검증 자료
- 현재 플레이어의 공정 상태
- 직전 실패 원인

근거 자료에 없는 내용은 확실한 사실처럼 단정하지 않는다.

예시:

“그 부분은 내가 가진 자료만으로는 정확히 말하기 어려워.”

### 2.4 힌트 방식

이음이는 정답을 곧바로 말하기보다 사고를 유도한다.

예시:

직접 답변:

“부재를 오른쪽으로 30도 돌려.”

권장 답변:

“홈의 방향과 돌출된 부분이 서로 마주 보고 있는지 살펴볼래?”

세 번째 실패 후 노장 시연 단계에서는 구체적인 설명을 허용한다.

## 3. F-013 PTT·STT·TTS 음성 대화

### 3.1 기능 정의

플레이어가 PTT 버튼을 사용해 이음이에게 질문하고 음성 답변을 듣는 기능이다.

### 3.2 입력 방식

자동 상시 듣기 방식은 사용하지 않는다.

PTT 버튼 누름  
↓  
마이크 입력 시작  
↓  
플레이어 발화  
↓  
PTT 버튼 놓음  
↓  
마이크 입력 종료  
↓  
STT 변환  
↓  
이음이 응답 생성  
↓  
TTS 재생

### 3.3 PTT 상태 표시

| **상태**  | **UI**                 |
|-----------|------------------------|
| 질문 가능 | PTT 아이콘 표시        |
| 듣는 중   | 마이크 아이콘 및 파형  |
| 변환 중   | 텍스트 변환 표시       |
| 생각 중   | 이음이 대기 애니메이션 |
| 답변 중   | 자막 및 발화 표시      |
| 사용 불가 | PTT 아이콘 비활성화    |

### 3.4 음성 인식 실패

첫 번째 실패:

“잘 못 들었어. 다시 한 번 말해 줄래?”

두 번째 연속 실패:

- 현재 공정에 맞는 선택형 질문 목록 표시
- 컨트롤러 레이와 트리거로 질문 선택
- 선택한 질문에 고정 또는 AI 응답 제공

### 3.5 작업과 무관한 질문

- 처음 1~2회는 짧게 응답 가능
- 이후 현재 공정으로 유도
- 반복적으로 무관한 질문을 해도 불이익 없음
- 평가 점수에 반영하지 않음

### 3.6 응답 길이

- 기본 응답: 음성 기준 5~10초
- 최대 응답: 15초
- 긴 설명이 필요한 경우 핵심만 먼저 전달
- 필요하면 플레이어가 다시 질문하도록 유도
