# PROJECT 이음 - UI 종류 및 개발 상태

> 기준일: 2026-08-12  
> 목적: 게임에서 사용하는 UI의 종류와 현재 개발 상태를 팀 내부에 공유한다.

## 분류 기준

- **지금 사용함**: UI 코드와 화면 에셋이 있으며, 프로젝트 씬에서 실행하거나 기능을 확인할 수 있는 상태
- **사용 예정**: 기획 문서에는 필요성이 정의되어 있으나 전용 UI 구현 또는 실제 콘텐츠 연결이 남아 있는 상태
- Unity/XR 패키지 샘플 UI와 개발자 디버그 전용 화면은 제품 UI 목록에서 제외한다.
- 현재 UI 일부는 기능 검증을 위한 화면 오버레이 방식이다. Meta Quest 3용 공간 UI·손목 UI 전환은 별도 작업으로 본다.

## 지금 사용함

| UI 종류 | 표시 내용 및 기능 | 현재 상태 |
|---|---|---|
| 메인 화면 | `게임 시작`, `이어하기`, `옵션`, `나가기` | `StartScene`에 연결되어 있음 |
| 새 게임 확인 창 | 기존 진행 기록이 있을 때 초기화 안내, `새로 시작`, `취소` | 메인 화면에서 사용 중 |
| 이어하기·저장 상태 안내 | 저장 없음, 저장 데이터 손상 등 상태 문구 표시 및 이어하기 버튼 활성화 제어 | 메인 화면에서 사용 중 |
| 옵션 화면 | 음악·대사·환경·영상 볼륨 슬라이더, 설정 저장 | 메인 화면과 일시정지 메뉴에서 공통 사용 |
| 일시정지 메뉴 | `계속하기`, `옵션`, `공정 다시 시작`, `메인 화면으로` | 테스트용 플레이 씬에 연결되어 있음. 공정 다시 시작은 이를 처리할 공정 시스템 연결이 필요함 |
| 메인 화면 이동 확인 창 | 현재 공정의 미완료 작업이 저장되지 않는다는 안내, `취소`, `메인 화면으로` | 일시정지 메뉴에서 사용 중 |
| 대사 자막 | 화자 이름과 대사 표시. 음성 볼륨과 독립적으로 표시 | 인게임 대사와 컷씬 대사에 공통 사용 |
| 컷씬 캡션 | 날짜, 장소, 최종 문구 등 화자가 없는 전체 화면 문구 | 프롤로그·엔딩 컷씬 시스템에서 사용 중 |
| 컷씬 건너뛰기 게이지 | 버튼을 누르고 있는 동안 건너뛰기 진행률 표시 | 컷씬 시스템에서 사용 중 |
| 영상 컷씬 화면 | mp4 컷씬을 화면에 표시. 화면 비율이 다르면 상하좌우를 검게 채움 | 런타임 생성. 재생 경로는 구현했으나 영상 파일이 아직 없어 미검증 |
| 이음이 음성 대화 HUD | 질문 가능·듣는 중·변환 중·생각 중·답변 중·사용 불가 상태, 마이크 입력량, 인식 문장, 답변 자막 표시 | AI 음성 대화 테스트 씬에서 사용 중. 현재는 화면 오버레이 방식 |
| 선택형 질문 목록 | 음성 인식이 반복 실패했을 때 현재 공정에 맞는 질문 버튼 표시 | 이음이 음성 대화 HUD에 구현되어 있음 |
| 화면 암전·전환 UI | 장면 전환과 컷씬 진입·종료 시 화면 페이드 | 공통 시스템에서 런타임 생성하여 사용 중 |

## 사용 예정

| UI 종류 | 표시 내용 및 기능 | 필요한 작업 |
|---|---|---|
| Quest용 공간 UI·손목 UI | 메인·일시정지·자막·이음이 HUD 등을 HMD에서 편하게 볼 수 있는 위치에 표시 | 현재 화면 오버레이 UI를 XR 공간 UI로 전환하고 컨트롤러 레이 조작 검증 |
| 현재 목표 안내 | 현재 공정과 해야 할 행동을 공정 시작 시 짧게 표시하고, 이후 손목 UI 등에서 다시 확인 | 공정 진행 데이터와 연결된 안내 UI 제작 |
| 조작 튜토리얼 안내 | 이동, 회전, 가리키기, 잡기·놓기, PTT 사용 순서를 단계별로 표시 | 튜토리얼 판정 시스템과 단계별 아이콘·문구 연결 |
| 컨트롤러·버튼 시각 안내 | 튜토리얼에서 입력이 없을 때 컨트롤러 위치와 눌러야 할 버튼을 표시 | 5초·10초·20초 단계별 도움 흐름 구현 |
| 상호작용 강조 | 잡을 수 있거나 현재 사용해야 하는 도구·부재의 외곽선 또는 밝기 강조 | 상호작용 가능 상태 및 공정 잠금 상태와 연결 |
| 잘못된 조작 안내 | 끌 위치 오류, 반대 방향 작업 등 잘못된 행동에 짧은 시각 안내 표시 | 공정별 오류 판정 이벤트와 안내 문구 연결 |
| 공정 평가 창 | `매우 우수`, `합격`, `불합격`, `도움 완료`, 잘한 점, 개선할 점 표시 | 먹매김·톱질·끌질·설치 평가 결과와 연결 |
| 평가 후 행동 버튼 | 평가 결과에 따라 `다음 작업`, `재도전`, `새 재료로 다시 하기` 제공 | 공정 재시작 및 다음 공정 이동 로직과 연결 |
| 도리·공포 설치 고스트 | 목표 위치와 방향에 파란색 반투명 부재 형태 표시 | 설치 판정·스냅 시스템과 연결 |
| 공포 퍼즐 참고 UI | 완성된 공포 구조 이미지와 현재 설치 순서를 참고할 수 있게 표시 | 퍼즐 데이터 및 단계 진행과 연결 |
| 공포 구조 완료 강조 | 퍼즐 완성 시 전체 구조를 시각적으로 강조 | 퍼즐 완료 연출과 연결 |
| 컨트롤러 연결·추적 안내 | 연결 또는 추적 유실 시 상태 안내, 입력 복구 전 메뉴 선택 제한 | XR 장치 상태 감지와 안내 UI 연결 |
| 저장·시스템 오류 안내 | 저장 실패, 장면 로딩 실패, AI 응답 실패 등 플레이 가능한 수준의 짧은 안내 | 공통 알림 UI와 오류별 메시지 정책 제작 |
| 진행 정지 도움 안내 | 일정 시간 입력이나 공정 변화가 없을 때 현재 목표와 힌트를 다시 안내 | 진행 정지 감지 시스템과 연결 |
| 로딩 진행 UI | 장면 로딩 상태 또는 진행률 표시 | 기존 로딩 진행값을 표시할 화면 제작 |
| 엔딩 결과 화면 | 완료 공정, 공정별 최고 평가, 도움 완료 여부, 잘한 작업, 배운 기술 표시 | 저장된 진행·평가 데이터를 읽는 결과 화면 제작 |
| 다시 보기 메뉴 | 프롤로그 다시 보기, 엔딩 결과 다시 보기 | 후순위 기능으로 메뉴와 재생 흐름 추가 |

## 현재 상태 요약

- 메뉴·옵션·자막·컷씬·이음이 대화처럼 게임의 공통 흐름에 필요한 UI는 기본 기능이 구현되어 있다.
- 실제 목공 체험에서 필요한 목표 안내, 튜토리얼, 도구 강조, 평가, 설치 고스트, 엔딩 결과 UI는 콘텐츠 시스템과 함께 구현해야 한다.
- 현재 구현된 화면 오버레이 UI는 기능 검증용 성격이 있으므로, 최종 빌드 전 Meta Quest 3에서 가독성·거리·컨트롤러 레이 조작을 검증해야 한다.
