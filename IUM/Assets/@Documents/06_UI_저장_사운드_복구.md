# PROJECT 이음 - UI·저장·사운드·복구

> [!info] 문서 출처

## 1. F-018 HUD 및 안내 UI

### 1.1 기능 정의

플레이어에게 현재 목표, 상호작용 가능 상태, 음성 질문 상태, 평가 결과를 제공하는 UI 기능이다.

### 1.2 주요 UI

| **UI**        | **표시 내용**                   |
|---------------|---------------------------------|
| 목표 안내     | 현재 수행할 공정                |
| 도구 강조     | 현재 사용해야 하는 도구         |
| PTT 아이콘    | 이음이 질문 가능 상태           |
| 자막          | 노장·이음이 대사                |
| 평가 창       | 매우 우수·합격·불합격·도움 완료 |
| 설치 고스트   | 부재 목표 위치와 방향           |
| 일시정지 메뉴 | 계속하기·옵션·메인 화면         |

### 1.3 목표 안내

공정 시작 시 짧게 표시한다.

예시:

현재 작업

먹줄을 사용해 도리에 기준선을 표시하세요.

상시 큰 패널로 표시하지 않고, 필요할 때 손목 UI나 작은 안내로 다시 확인할 수 있도록 한다.

### 1.4 자막

- 노장과 이음이의 모든 대사에 자막 제공
- 화자 이름 표시
- 긴 문장은 2줄 이내로 분리
- 음성과 자막 재생 시점 동기화
- 대사 볼륨이 0이어도 자막은 표시

### 1.5 평가 창

공정 종료 시 다음을 표시한다.

- 평가 점수
- 잘한 점
- 개선할 점
- 재도전 또는 다음 단계

예시:

합격

먹선을 따라 안정적으로 절단했습니다.

절단면의 왼쪽이 조금 기울어졌습니다.

\[다음 작업\]

불합격 시:

불합격

홈의 깊이가 목표보다 깊습니다.

\[새 재료로 다시 하기\]

## 2. F-019 일시정지 메뉴

### 2.1 기능 정의

플레이 도중 게임을 일시정지하고 옵션을 조정하거나 메인 화면으로 이동하는 기능이다.

### 2.2 메뉴 항목

계속하기

옵션

공정 다시 시작

메인 화면으로

### 2.3 공정 다시 시작

- 현재 공정 데이터를 초기화
- 현재 공정 시작 지점으로 복귀
- 작업 중 부재는 실패 부재로 기록하지 않음
- 재시작 횟수를 평가에 포함할지는 추후 결정

### 2.4 메인 화면으로 이동

확인 문구:

“현재 공정의 작업 내용은 저장되지 않습니다. 메인 화면으로 돌아가시겠습니까?”

확정 시:

- 마지막으로 완료한 공정까지 저장
- 현재 공정의 부분 작업은 폐기
- 메인 화면 이동

## 3. F-020 저장 및 이어하기

### 3.1 기능 정의

게임 진행 상황과 옵션을 하드웨어 내부에 자동 저장하고 다음 실행에서 이어서 플레이하는 기능이다.

### 3.2 저장 시점

- 프롤로그 완료
- 튜토리얼 완료
- 각 공정 통과
- 도움 완료 발생
- Chapter 1 완료
- 도리 설치 완료
- 공포 퍼즐 완료
- 엔딩 완료
- 옵션 변경

작업 도중의 절단면이나 홈 형상은 저장하지 않는다.

### 3.3 저장 데이터

saveVersion

hasSaveData

prologueCompleted

tutorialCompleted

currentChapter

nextProcess

makmeokGrade

sawingGrade

chiselingGrade

gongpoPuzzleCompleted

endingCompleted

옵션 데이터:

musicVolume

dialogueVolume

environmentVolume

### 3.4 이어하기 위치

저장 데이터는 항상 다음 공정의 시작 지점을 가리킨다.

예시:

| **마지막 완료 상태** | **이어하기 위치**             |
|----------------------|-------------------------------|
| 프롤로그 완료        | 튜토리얼                      |
| 튜토리얼 완료        | 먹매김                        |
| 먹매김 완료          | 톱질                          |
| 톱질 완료            | 끌질                          |
| Chapter 1 완료       | 도리 설치                     |
| 도리 설치 완료       | 공포 퍼즐                     |
| 엔딩 완료            | 메인 화면 또는 엔딩 다시 보기 |

### 3.5 저장 슬롯

저장 슬롯은 1개만 사용한다.

로그인과 사용자별 프로필은 제공하지 않는다.

동일 하드웨어를 여러 사람이 사용할 경우 이전 사용자의 기록이 남을 수 있으므로, 메인 화면에서 새 게임 선택 시 초기화 안내를 명확히 표시한다.

### 3.6 저장 오류

저장에 실패하더라도 게임을 강제로 종료하지 않는다.

- 저장 재시도
- 실패 시 내부 오류 기록
- 플레이어에게 간단한 안내
- 기존 정상 저장본이 있다면 덮어쓰지 않음

## 4. F-022 사운드 시스템

### 4.1 사운드 분류

#### 음악

- 메인 화면
- 프롤로그
- 작업장
- 엔딩

#### 대사

- 노장
- 이음이
- 내레이션

#### 환경 및 효과음

- 바람
- 작업장 소리
- 먹줄
- 톱질
- 톱밥
- 끌질
- 망치
- 목재 파손
- 부재 설치
- UI 선택

### 4.2 3D 사운드

도구와 목재에서 발생하는 소리는 실제 발생 위치를 기준으로 재생한다.

노장 음성도 노장의 위치를 기준으로 재생하되, 중요한 안내는 지나치게 작아지지 않도록 최소 음량을 보장한다.

이음이의 음성은 플레이어 가까이에서 들리는 안내 음성으로 처리할 수 있다.

## 5. F-023 오류 및 복구 시스템

### 5.1 복구 대상

- 도구 분실
- 부재 분실
- 설치 부재 이탈
- 작업 상태 정지
- AI 응답 실패
- 음성 인식 실패
- 저장 실패
- 장면 로딩 실패
- 컨트롤러 추적 유실

### 5.2 공정 진행 정지 감지

일정 시간 동안 다음 변화가 없으면 진행 정지 가능성을 확인한다.

- 도구 이동
- 부재 이동
- 가공 진행도 변화
- 플레이어 위치 변화
- PTT 사용
- UI 입력

30초 이상 진행이 없으면 이음이 또는 노장이 현재 목표를 다시 안내한다.

### 5.3 강제 복구

플레이어가 기능을 진행할 수 없는 경우 일시정지 메뉴에서 공정 다시 시작을 사용할 수 있다.

공정 다시 시작 시:

- 도구 원위치
- 신규 부재 지급
- 현재 공정 데이터 초기화
- 노장 설명부터 다시 시작
