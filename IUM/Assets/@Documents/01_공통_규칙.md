# PROJECT 이음 - 공통 규칙

## 1. 공통 규칙

### 1.1 CR-01 오브젝트 보존

플레이어가 사용하는 도구와 부재는 별도의 처리 없이 사라지거나 복제되지 않는다.

- 도구를 작업 공간 밖으로 떨어뜨리면 일정 시간 후 원래 위치로 복귀한다.
- 부재가 가공 실패 상태가 되면 자동 삭제하지 않는다.
- 실패한 부재는 작업대 옆의 배운 흔적 공간으로 이동한다.
- 새 부재는 새 재료 지급 기능을 통해서만 생성한다.
- 동일한 역할의 신규 부재가 동시에 두 개 이상 활성화되지 않도록 관리한다.
- 장면 전환 중에는 기존 오브젝트를 저장하거나 명시적으로 제거한다.

### 1.2 CR-02 컨트롤러 기반 조작

모든 주요 조작은 Meta Quest 3 컨트롤러를 기준으로 한다.

기본 입력은 다음과 같다.

| **입력**         | **기본 기능**           |
|------------------|-------------------------|
| 그립 버튼 누르기 | 도구 또는 부재 잡기     |
| 그립 버튼 놓기   | 잡고 있는 오브젝트 놓기 |
| 트리거           | 도구 작동, UI 선택      |
| 스틱             | 이동 또는 회전          |
| 메뉴 버튼        | 일시정지 메뉴           |
| 지정 PTT 버튼    | 이음이 음성 질문        |

구체적인 버튼 배치는 개발 과정에서 Meta XR SDK 입력 설정에 맞춰 확정한다.

### 1.3 CR-03 오브젝트 분실 방지

도구나 부재가 다음 영역에 들어가면 복구 대상으로 판단한다.

- 플레이 공간 바닥 아래
- 작업장 벽 바깥
- 플레이어가 접근할 수 없는 공간
- 지정된 복구 경계 밖
- 물리 오류로 지나치게 빠르게 이동하는 상태

복구 대상이 된 도구는 3초 뒤 원래 배치 위치로 돌아간다.

부재는 상태에 따라 다음과 같이 처리한다.

- 가공 전 부재: 재료 지급 위치로 복귀
- 작업 중 부재: 작업대의 현재 공정 위치로 복귀
- 실패 부재: 배운 흔적 공간으로 이동
- 설치 완료 부재: 자동 복구 대상에서 제외

### 1.4 CR-04 이음이 질문 가능 상태

플레이어는 다음 상황을 제외하면 이음이에게 질문할 수 있다.

- 프롤로그 또는 회상 영상 재생 중
- 장면 전환 중
- 로딩 중
- 노장의 필수 대사 재생 중
- 이음이의 기존 답변 재생 중
- 노장의 작업 시연 중
- 평가 결과 연출 중
- 마이크 사용 권한이 없는 경우

질문할 수 있는 상태에서는 화면 또는 손목 UI에 PTT 아이콘을 표시한다.

### 1.5 CR-05 AI 응답 지연 처리

이음이의 응답은 STT, LLM 응답 생성, TTS 처리 과정을 거친다.

- 4초 이내 응답 준비 완료: 정상 재생
- 4초 초과: “음, 잠시 생각해 볼게.” 등의 대기 음성 재생
- 10초 초과: 현재 공정에 대응하는 고정 힌트 대사로 대체
- 15초 초과: 요청 실패 처리 후 작업을 계속할 수 있도록 복귀

응답 실패로 게임 진행이 멈추어서는 안 된다.

### 1.6 CR-06 인터넷 연결 실패 처리

인터넷 연결이 끊기거나 외부 AI 서비스가 응답하지 않더라도 게임의 핵심 공정은 계속 진행할 수 있어야 한다.

오프라인 상태에서는 다음 기능을 사용한다.

- 공정별 고정 설명
- 공정별 1차·2차 힌트
- 격려 대사
- 오류 안내 대사
- 평가 결과별 고정 피드백
- 작업 원리의 짧은 설명

인터넷 연결이 필요한 기능은 이음이의 자유 질문 응답으로 한정한다.

### 1.7 CR-07 청소년 대상 응답 안전성

이음이의 응답은 화면과 음성으로 출력되기 전에 안전성 검사를 거친다.

검사 대상은 다음과 같다.

- 욕설 및 비속어
- 성적 표현
- 지나치게 폭력적인 표현
- 혐오 또는 차별 표현
- 개인정보 요구
- 위험 행동 유도
- 자해 또는 타해 유도
- 역사적 사실을 근거 없이 단정하는 내용
- 게임 및 전통 목조건축과 무관한 부적절한 내용

응답이 기준을 통과하지 못하면 다음과 같은 안전 응답으로 대체한다.

“그 내용은 내가 답하기 어렵겠어. 지금 하고 있는 작업에 관해 궁금한 것을 물어봐 줘.”

### 1.8 CR-08 판정 일관성

작업 성공 여부와 등급은 사전에 정의된 계산 규칙으로만 결정한다.

- AI가 합격 여부를 직접 결정하지 않는다.
- 동일한 작업 데이터에는 동일한 판정 결과가 나와야 한다.
- AI는 계산된 판정 결과를 설명하는 문장만 생성할 수 있다.
- AI 응답 생성에 실패해도 판정 결과는 변경되지 않는다.
- 판정 기준 변경 시 문서 버전과 게임 빌드 버전을 함께 기록한다.

### 1.9 CR-09 불합격 및 재도전

각 공정에서 불합격 판정을 받으면 플레이어는 해당 공정을 다시 수행한다.

- 재도전 횟수에는 제한이 없다.
- 불합격 횟수가 일정 수에 도달해도 자동으로 합격 처리하지 않는다.
- 노장이 대신 작업하여 공정을 완료하는 기능은 사용하지 않는다.
- 도움 완료 등급은 사용하지 않는다.
- 플레이어가 합격 기준을 충족할 때까지 동일 공정을 반복할 수 있다.
- 반복 실패 시에도 게임을 강제로 다음 공정으로 진행시키지 않는다.
- 실패할 때마다 새 부재를 지급하며, 기존 실패 부재는 배운 흔적 공간에 남긴다.
- 플레이어는 일시정지 메뉴를 통해 공정을 처음부터 다시 시작할 수 있다.

진행 구조는 다음과 같다.

> 공정 수행
>
> ↓
>
> 평가
>
> ↓
>
> 매우 우수 또는 합격
>
> ├─ 예 → 다음 공정
>
> └─ 아니오
>
> ↓
>
> 불합격 피드백
>
> ↓
>
> 새 부재 지급
>
> ↓
>
> 동일 공정 재시작
>
> ↓
>
> 합격할 때까지 반복

### 1.10 CR-10 평가 단계

각 작업 결과는 다음 네 가지 중 하나로 기록한다.

| **결과**  | **의미**                       |
|-----------|--------------------------------|
| 매우 우수 | 목표 범위에 높은 정확도로 도달 |
| 합격      | 최소 통과 기준 충족            |
| 불합격    | 통과 기준 미달                 |

### 1.11 CR-11 로컬 저장

게임에는 로그인 기능과 서버 계정 기능을 사용하지 않는다.

저장 정보는 Meta Quest 3 하드웨어 내부에 기록한다.

저장 대상은 다음과 같다.

- 현재 진행 챕터
- 마지막으로 완료한 공정
- 각 공정의 최고 평가
- 공정별 시도 횟수
- 도움 단계
- 옵션 설정
- 프롤로그 및 튜토리얼 완료 여부
- 엔딩 완료 여부

음성 원본과 플레이어의 전체 발화 텍스트는 저장하지 않는다.
